# 🚀 Payroll ETL Processing with Python & Pandas

Automated ETL pipeline developed in Python to transform unstructured payroll spreadsheets exported from a legacy accounting system into a clean, structured, and analysis-ready dataset.


# 📌 Project Overview

This project was created to solve a major operational bottleneck involving payroll spreadsheets generated by a legacy accounting platform.

The original files were exported in a semi-structured format, containing:

* fragmented data blocks
* inconsistent layouts
* repeated sections
* dynamic row positioning
* poor analytical usability

The process of manually organizing and consolidating this information demanded several days of work from the operations team every month.

Using Python and Pandas, the entire workflow was automated through a custom ETL process capable of:

* identifying employee sections dynamically
* extracting payroll events
* restructuring the dataset
* converting payroll codes into analytical columns
* exporting a standardized Excel dataset ready for reporting and auditing


# 🧠 Business Problem

The payroll files generated by the accounting system were not designed for analytical processing.

### Main challenges:

* Non-tabular spreadsheet structure
* Payroll events distributed vertically
* Dynamic row positioning
* Manual consolidation effort
* High operational workload
* Slow auditing and contract validation process

The original operational workflow was inefficient and highly time-consuming.


# ✅ Solution

A complete ETL pipeline was developed using Python and Pandas to automatically:

* Read legacy `.xls` payroll files
* Detect employee sections dynamically
* Locate payroll event blocks
* Extract employee metadata
* Convert payroll codes into columns
* Normalize the dataset
* Export a structured `.xlsx` file

The final output became fully compatible with:

* Excel analysis
* Power BI dashboards
* auditing processes
* contract measurement validation
* financial reconciliation

## 4. Payroll Event Mapping

Payroll event codes are dynamically transformed into analytical columns.

Example:

| Payroll Code | Generated Column |
| ------------ | ---------------- |
| 10           | "10"             |
| 19           | "19"             |
| 301          | "301"            |

This allows the final spreadsheet to behave like a structured database table.
