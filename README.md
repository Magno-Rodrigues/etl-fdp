# 🚀 Payroll ETL Automation with Selenium & Pandas

Automated payroll extraction, transformation, and consolidation pipeline developed in Python using Selenium and Pandas.

This project was created to eliminate manual processing of payroll spreadsheets generated by a legacy accounting system, transforming unstructured reports into organized datasets ready for analysis and operational control.


# 📌 Project Overview

The accounting system generated monthly payroll spreadsheets in poorly structured `.xls` files, containing:

* fragmented data
* inconsistent formatting
* mixed layouts
* sequential records without tabular structure

The manual consolidation process required several days of work from the operational team every month.

To solve this problem, an end-to-end automation pipeline was developed combining:

* Web Automation
* Automated Downloads
* ETL Processing
* Data Structuring
* Excel Export Automation


# ⚡ Main Features

## 🌐 Web Automation with Selenium

The automation performs:

* login into the corporate system
* iframe navigation
* multi-tab browser control
* dynamic element interaction
* report filtering
* automated CSV downloads

### Complex Navigation Handling

One of the biggest technical challenges was browser automation within a legacy web system.

The system contained:

* multiple iframes
* dynamic IDs
* nested screens
* asynchronous loading
* hidden elements

To overcome this, the automation uses:

* `WebDriverWait`
* `Expected Conditions`
* iframe switching
* XPath navigation
* dynamic waits
* tab/session control


# 🔄 ETL Pipeline

After downloading the reports, the ETL process automatically:

* reads raw `.xls` and `.csv` files
* extracts employee payroll data
* restructures semi-structured spreadsheets
* maps payroll codes into columns
* removes unnecessary data
* standardizes outputs
* exports clean Excel files

# 🧠 Technical Challenges

## Legacy Web System Automation

The corporate system used:

* nested iframes
* inconsistent HTML structures
* dynamic components
* delayed rendering

This required advanced Selenium handling techniques to ensure stability and reliability.


## Semi-Structured Spreadsheet Processing

The payroll reports were not organized as conventional tables.

The ETL logic had to:

* identify patterns dynamically
* detect payroll sequences
* reconstruct employee records
* generate structured datasets programmatically
